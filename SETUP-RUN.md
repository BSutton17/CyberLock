# How to Run/Setup (From Sean)
* Install node.js from https://nodejs.org/en/download
* 
* Make a folder on your machine and the clone the repo into it
* 
* Open in VSCode and then open two terminals and cd SeniorCapstone/Client in one and SeniorCapstone/Server in the other
* 
* In both terminals type npm install
* 
* To run the app first in the server terminal type node index.js then in the client terminal cd src then npm run dev and you should be able to see the app running
